# 反向番茄钟 Android

这是手机上的第一版 Android MVP。

目前已经有：

- 悬浮小球显示工作倒计时
- 按住小球拖动位置
- 双击小球展开控制条
- 展开后支持 `+1`、暂停、直接休息、收起和退出
- 展开控制条改为两行大按钮，方便手机点击
- 暂停时会按真实经过时间恢复工作倒计时
- 工作倒计时结束或连续工作达到上限后进入休息
- 休息页半透明覆盖屏幕
- 休息正计时
- 满最短休息时间后，手动选择回到工作
- 锁屏后按真实经过时间结算，解锁后倒计时会补算

## 运行

用 Android Studio 打开这个 `android/` 目录。

连接 Android 手机，运行 `app`。

首次运行后，在应用里点 `允许悬浮窗权限`。

Android 13 及以上还需要点 `允许通知权限`。

然后点 `启动守卫`。

## 默认设置

- 下一轮工作：25 分钟
- 最短休息：5 分钟
- 连续工作上限：50 分钟

## 当前限制

这一版还没有做正式签名安装包、误触退出休息、日志查看和跨设备同步。

Android 的后台保活会受不同手机系统影响。荣耀 / MagicOS 上如果悬浮窗消失，需要把应用加入后台运行白名单，并关闭电池优化。
